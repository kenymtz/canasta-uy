# Evaluación

Conjuntos de prueba etiquetados a mano para medir la calidad del proyecto:

- `matching/` — pares (producto de la fuente → producto canónico correcto) para medir
  precisión y recall del matching entre países e idiomas.
- `tickets/` — tickets de ejemplo **anonimizados** con su extracción correcta, para medir
  qué porcentaje de ítems se extrae bien.

Los resultados de cada versión se registran acá para poder comparar mejoras.
